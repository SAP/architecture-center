## Key features

SAP Reltio Sources tab showing crosswalk after merges with survivorship.

Real-time, unified data products
Publish unified master data as data products that read and write in milliseconds through APIs and streaming—at high volume worldwide. Access controls, consent, and lineage travel with the data, feeding operational applications, analytics, the knowledge core, and AI agents from one governed source.

AI-augmented entity resolution and enrichment
Patented LLM-powered entity resolution works alongside matching rules to identify when data from different sources describe the same entity, including matches that rules alone may not detect. SAP Reltio then builds the resolved entity automatically: cleansing and standardizing values with attributes and interactions from third-party and unstructured sources.

Multidomain, comprehensive entity views
Get multidomain views that carry each entity’s attributes, relationships, hierarchies, and interactions, drawn from structured and unstructured sources. Survivorship rules decide which values wins when sources disagree, across customers, products, suppliers, locations, and assets.

Dynamic knowledge graph
Represent entities, relationships, and hierarchies in a knowledge graph built on an extensible, machine-interpretable ontology. Applications and AI agents can access business context directly instead of reassembling those relationships every time they ask a question.

Continuous data quality and stewardship
Profile and monitor master data against business rules, trace issues to root causes, prioritize issues by business impact, and remediate records in bulk. Prebuilt agents for match resolution, data quality, and enrichment automate stewardship tasks as sources evolve, so quality holds instead of decaying.

Industry-specific velocity packs
Each velocity pack includes an industry ontology, prebuilt configurations, prepackaged connectors, and documentation, helping teams extend an existing data model instead of creating one from scratch. More than 1,000 connectors and an API-first architecture connect SAP and non-SAP sources without custom pipelines.
