The Enterprise Catalog is the central metadata and discovery hub within SAP Business Data Cloud. It plays the following roles:

Data Product Discovery It serves as the place where consumers can find and explore SAP-curated Data Products — structured, governed datasets sourced from SAP applications (S/4HANA, SuccessFactors, Ariba, etc.). The feature "Discover SAP Data Products in catalog" is explicitly modelled as a solution feature of BDC.

Single Catalog for Company Data BDC positions the catalog as a "One Data Catalog for your company data" — a unified surface that consolidates both SAP and non-SAP data assets across the enterprise under a single discovery experience.

Metadata Enrichment The catalog stores and exposes rich metadata for each data product — semantics, lineage, ownership, and quality attributes — as evidenced by the innovation node "Enriching data products with catalog metadata". This enables informed consumption decisions without needing to access the underlying system.

Governed Data Product Lifecycle The BDC domain model explicitly tracks Data Products with Output Ports, Packages, and CSN Types/Elements — all surfaced and navigable through the catalog. It acts as the governance layer that makes data products findable, understandable, and trustworthy.
