Decentralized Identity Verification (DIV) is a multi-tenant BTP service that enables apps to use Self-sovereign Identity (SSI) for inter-company communications. DIV provides the possibility to sign, verify, and manage verifiable credentials. This is the basis for decentralized network and the web 3 technologies of the future.



DIV was development in the context of the data sovereignty requirements of Catena-X and Gaia-X. The basis for DIV was created by ICN and brought to the first release by a joint development project of ICN and BTP-Foundation.
